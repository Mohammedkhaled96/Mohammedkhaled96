## 🚀 About me

- 🧠 I build **agentic APIs** where LLMs safely drive real business logic through function calling — .NET 9, Semantic Kernel and local Llama 3.2 via Ollama.
- 🛡️ I design for resilience: deterministic fallback agents, Clean Architecture, health checks and structured logging.
- ♿ I care deeply about **accessibility** — I ship tools for screen-reader users, from NVDA add-ons to an accessible AI-powered terminal.
- 🌍 I build bilingual products with first-class **English & Arabic (RTL)** support.
- ⚙️ Every project ships with CI/CD on GitHub Actions.
